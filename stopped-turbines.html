Como funciona
  1. A página lê as abas Fonte de Dados de Essentia e Auren, além de Historic e Historic - Auren.
  2. Entram como paradas as linhas com Status = Parada; os retornos vêm das linhas com data de retorno recente.
  3. Os dias parados, percentuais e comparativos são recalculados automaticamente.
  4. Ao final, baixe o arquivo dados-stopped-turbines.js e faça commit para publicar ao time.
A planilha é lida dentro do seu navegador. Nenhum dado é enviado para servidor.
